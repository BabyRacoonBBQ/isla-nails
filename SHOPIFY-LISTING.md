# Shopify listing plan

The 202609 edit uses one product listing per nail design photo. Each listing represents one reusable set of 10 nails and uses a single `ONE SIZE` variant.

## Collections

- **Tidal Garden** — sea-glass, floral, shell, fruit and beach motifs.
- **Night Signal** — black lacquer, chrome, gothic and nocturnal motifs.
- **Holiday Atelier** — winter, ribbon, candy-cane and festive motifs.
- **Studio Gloss** — single-color editorial gloss.

## Listing fields

- **Title:** use the editorial product name from `src/main.jsx`.
- **Description:** explain the palette, motifs and finish; keep the copy specific to this design.
- **Product category:** choose the closest Shopify standard category for artificial/press-on nails.
- **Product type:** `Reusable press-on nail set`.
- **Collection:** use one of the four collections above.
- **Variant:** `ONE SIZE` only; do not add XS/S/M/L variants.
- **Inventory:** one stock quantity per product; the current demo values are placeholders until Shopify inventory is entered.
- **Media:** use the derived web copies in `public/images/202609/`; keep `raw_data/202609/` unchanged.
- **Tags:** `one-size`, `reusable`, plus the collection name and motif keywords.
- **SEO:** write a descriptive title and meta description for each product; avoid changing handles after publishing.

## Import handoff

Shopify login is not required to prepare the site or this mapping. Login or a Shopify CSV/import permission is only needed when these listings are uploaded to the store and published to sales channels.
