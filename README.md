# ISLA Nails concept store

An immersive, responsive luxury nail-art storefront concept.

## Run locally

```powershell
npm install
npm run dev
```

The working brand name `ISLA` and catalog content live in `src/main.jsx`. Product photos for the 202609 edit are served from `public/images/202609/`.

`raw_data/` is an immutable original-asset archive. Do not edit, rename, move, delete, compress, crop, or overwrite anything inside it. See [AGENTS.md](AGENTS.md) and [SHOPIFY-LISTING.md](SHOPIFY-LISTING.md) for the asset and listing rules.
